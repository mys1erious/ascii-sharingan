# ASCII Sharingan

A Sharingan made of ASCII: rain → tomoe → mangekyō → chidori → amaterasu. Every frame is monospace text, and the sound is
synthesised in the browser. One HTML file, no dependencies.

**Live:** https://mys1erious.github.io/ascii-sharingan/

Click, swipe or draw a circle to interact.

| URL parameter | Effect |
|---|---|
| `?style=1..4` | 1 Manga ink · 2 Crimson (default) · 3 Phosphor · 4 Akatsuki |
| `?grid` | All 4 styles at once in a 2×2 grid |
| `?clean` | No labels or hints (for recording) |
| `?t=9.6` | Freeze on that moment; add `&play` to keep running from there |
| `?seed=11` | Change the random seed (rain and crow layout) |
